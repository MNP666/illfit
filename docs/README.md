# Planning Docs

This folder holds versioned planning documents for the project.

Naming convention:

- `PRD_0p2.md`: product requirements / iteration brief for version 0.2
- `ISSUES_0p2.md`: implementation issues and milestones for version 0.2

Future iterations should follow the same pattern:

- `PRD_0p3.md`
- `ISSUES_0p3.md`
- `PRD_0p4.md`
- `ISSUES_0p4.md`

The goal is not heavyweight process. These files exist to keep each iteration
focused, explicit, and reviewable before we write or refactor code.
